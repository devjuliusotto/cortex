# Cortex website media

Drop product screenshots and videos in this folder.

Recommended filenames already wired into the page:

- `video-geral.mp4` or `video-geral.webm`
- `1.png`, `1.jpg`, `1.jpeg`, or `1.webp`
- `2.png`, `2.jpg`, `2.jpeg`, or `2.webp`
- `3.png`, `3.jpg`, `3.jpeg`, or `3.webp`
- `4.png`, `4.jpg`, `4.jpeg`, or `4.webp`
- `5.png`, `5.jpg`, `5.jpeg`, or `5.webp`

Legacy fallback video names still work:

- `cortex-overview.mp4`
- `cortex-overview.webm`

If a file is missing, the website shows a generated product mockup instead of a broken media element.
